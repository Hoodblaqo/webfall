# WEBFALL

An original, mobile-first cinematic landing page inspired by the supplied Spider-Man city lock-screen photo and the immersive, minimal 3D storytelling mood of igloo.inc.

## Live site
https://hoodblaqo.github.io/webfall/

## Features
- Scroll-driven narrative and progress line
- Pointer-reactive layered city scene
- Animated original vector acrobat and faceted ice shard
- Canvas starfield, web geometry, scan beam and atmospheric glow
- Mobile layout and reduced-motion support
- No build step or external JS dependencies
